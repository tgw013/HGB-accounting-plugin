# ISSUES_LOG — Praxisfehler-Tracking

Dieses Dokument sammelt **konkrete Praxis-Befunde**: Stellen, an denen der Plugin-Output durch Steuerberater-Review korrigiert werden musste, oder wo der Plugin-Vorschlag in einer konkreten Anwendung suboptimal war.

**Zweck:** Iterative Verbesserung des Plugins basierend auf Real-World-Anwendung statt teurem Upfront-Audit.

---

## Format pro Eintrag

```markdown
## YYYY-MM-DD — [Skill/Bereich] — [Kurz-Titel]

**Sachverhalt:** Welche Anfrage / welcher Use Case?

**Plugin-Output (Vorschlag):** Was hat das Plugin vorgeschlagen?

**Korrektur durch Steuerberater / WP:** Was war tatsächlich richtig?

**Ursache (im Plugin):** Warum war der Vorschlag nicht optimal?
- [ ] Falscher Konto-Verweis
- [ ] Veraltete Rate / Schwellenwert
- [ ] Falsche §-Citation
- [ ] Konzeptionelle Fehlinterpretation
- [ ] Sektor-Sachverhalt (Plugin-Out-of-Scope)
- [ ] Sonstiges: ___

**Plugin-Anpassung:** Welche Änderung wurde / wird im Plugin gemacht?
- Datei: ___
- Commit: ___

**Status:** [ ] Open  [ ] Fixed in Plugin  [ ] Out-of-Scope (Hinweis ergänzt)
```
